# Papelería PuntoEscolar

Aplicación Android nativa en Kotlin para administrar el inventario, las ventas y los reportes de una papelería. El acceso está protegido con huella dactilar (BiometricPrompt).

## Funciones
- Login con huella dactilar
- Inventario de productos
- Registro de ventas
- Reportes
- Cierre de sesión

## Requisitos
- Android Studio
- Android 7.0 (API 24) o superior

## Cómo ejecutarlo
1. Clona el repositorio.
2. Ábrelo en Android Studio y espera la sincronización de Gradle.
3. Ejecuta la app en un dispositivo o emulador con huella registrada.
